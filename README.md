# Portafolio de Ronney

Plantilla lista para desplegar en Vercel con Next.js.

## Personalizar
1. Reemplaza los textos de `app/page.js`.
2. Coloca tu currículum como `public/cv.pdf`.
3. Si quieres usar una foto real, colócala en `public/foto.jpg` y reemplaza el bloque `photoPlaceholder` por una imagen.
4. Cambia `tuemail@ejemplo.com` por tu correo.

## Ejecutar localmente
```bash
npm install
npm run dev
```

## Publicar en Vercel
Sube el proyecto a GitHub e impórtalo en Vercel, o despliega directamente desde Vercel.
